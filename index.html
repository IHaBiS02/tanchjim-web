Linux: 권한 오류가 날 때

      
브라우저가 장치에 접근하려면 udev 규칙이 한 번 필요합니다. 터미널에서 실행한 뒤 장치를 다시 꽂아 주세요.

      
echo 'SUBSYSTEM=="usb", ATTRS{idVendor}=="2fc6", ATTRS{idProduct}=="f0f0", TAG+="uaccess"
KERNEL=="hidraw*", ATTRS{idVendor}=="2fc6", ATTRS{idProduct}=="f0f0", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-tanchjim.rules
sudo udevadm control --reload && sudo udevadm trigger

      
      
위 규칙은 LUNA AT(2fc6:f0f0)용입니다. 다른 기기는 연결 시 로그에 나오는 USB ID로 idVendor / idProduct를 바꿔 넣으세요.


      
Windows

      
Windows에서는 WebUSB로 오디오 장치에 접근할 수 없어 WebHID(쓰기 전용)로 연결합니다. 현재 설정값은 읽어올 수 없습니다.


      
다른 프로그램과 동시 사용

      
공식 앱이나 다른 탭에서 같은 장치를 열고 있으면 연결이 실패할 수 있습니다.
